# AI-Driven Engineering Leader Portfolio

A modern, animated portfolio website built with Next.js 14, TypeScript, and Tailwind CSS showcasing AI transformation leadership and technical excellence.

## Features

- 🎨 **Modern 2025 Design** - Clean, professional design with smooth animations
- ⚡ **Next.js 14 App Router** - Server-side rendering for optimal performance and SEO
- 🎭 **Framer Motion Animations** - Engaging, smooth animations throughout
- 📱 **Fully Responsive** - Perfect on all devices from mobile to desktop
- 🌙 **Dark Mode Support** - Automatic dark mode based on system preferences
- 📊 **Interactive Metrics** - Animated counters and data visualizations
- 🎯 **SEO Optimized** - Perfect for recruiter discovery

## Key Sections

1. **Hero** - Dynamic role rotation with compelling value proposition
2. **Impact Dashboard** - Animated metrics showing measurable results
3. **Case Studies** - Interactive cards highlighting real transformation projects
4. **Technical DNA** - Categorized tech skills with progress bars
5. **Leadership Philosophy** - Frameworks and principles with testimonials
6. **Contact** - Multiple ways to connect

## Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Build for Production

```bash
# Create optimized production build
npm run build

# Start production server
npm run start
```

## Customization

### Update Personal Information

1. **Contact Links** - Edit links in `components/Footer.tsx` and `components/Leadership.tsx`
2. **Metrics** - Update your impact numbers in `components/ImpactDashboard.tsx`
3. **Case Studies** - Modify case studies array in `components/CaseStudies.tsx`
4. **Tech Stack** - Update skills in `components/TechnicalDNA.tsx`
5. **Leadership Content** - Edit principles and testimonials in `components/Leadership.tsx`

### Styling

- Colors and gradients: `tailwind.config.ts`
- Global styles: `app/globals.css`
- Component-specific styles: Inline Tailwind classes
